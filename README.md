# Mochi-AI-DeskMate
 An AI-powered desktop companion integrating Arduino hardware with Python-based AI processing. Features touch-sensor navigation, OLED feedback, and real-time environmental monitoring."

 READ THE connections.txt FILE TO KNOW HOW TO CONNECT YOUR DESKMATE ON A BREADBOARD.
 
 mochi_stream.py IS THE PYTHON CODE WHICH YOU HAVE TO DOWNLOAD AMD RUN IN THE TERMINAL TO STREAM.
 
 new_ai_mochi IS THE ARDUINO .ino FILE WHICH YOU HAVE TO UPLOAD TO THE ARDUINO.
